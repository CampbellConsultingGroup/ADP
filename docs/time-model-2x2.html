Notes for implementation: this is a static reference for the Portfolio screen (Layer 2, Application/Enterprise domain), not a working component. Quadrant boundaries are drawn at the midpoint (50/50) with a light quadrant tint rather than a hard divider, since criticality/fit are continuous scores, not a binary split. Bubble size encodes a third metric (cost or user count) — pull real values from the application registry rather than a fixed radius. Colors map 1:1 to the four time_disposition values already in the data model. Sensitive fields (cost, risk) feeding bubble size should stay behind the existing sensitivity-gated read permission, same as the rest of Portfolio Analysis. Recommend implementing as a React Flow or Recharts scatter with dagre unused (no layout needed, fixed cartesian plot) — clicking a bubble should route to the application detail view.
