## Python Entities (Pydantic v2, `extra="forbid"`)

### `ElementStyle`

Styling for one element type in the locked theme. All fields required.

| Field | Type | Constraints | Notes |
|---|---|---|---|
| `fill` | `str` | 7-char hex `#RRGGBB` | Background fill color |
| `stroke` | `str` | 7-char hex `#RRGGBB` | Border stroke color |
| `color` | `str` | 7-char hex `#RRGGBB` | Text/foreground color |
| `shape` | `Literal["box", "actor", "cylinder", "hexagon"]` | — | Visual shape; `actor` for person, `box` for system/container/component, `cylinder` for future datastores |
| `font_size` | `int` | `>= 8, <= 24` | Label font size in pixels |
| `font_weight` | `Literal["normal", "bold"]` | — | Label font weight |

### `RelationshipStyle`

Styling for all relationship lines in the locked theme. All fields required.

| Field | Type | Constraints | Notes |
|---|---|---|---|
| `stroke` | `str` | 7-char hex | Arrow/line color |
| `stroke_width` | `float` | `> 0` | Line width in pixels |
| `arrow_end` | `Literal["open", "filled", "none"]` | — | Arrowhead type at target end |

### `LockedTheme`

Root entity for the locked theme artifact (`c4-theme.json`). Validates against `c4-theme.schema.json`.

| Field | Type | Constraints | Notes |
|---|---|---|---|
| `version` | `str` | Semantic version `MAJOR.MINOR.PATCH` | Version of this theme artifact |
| `locked` | `Literal[True]` | Must be `True` — not `false`, not absent | ART-XII enforcement at the type level |
| `styles` | `dict[ElementKind, ElementStyle]` | Must contain all four `ElementKind` values | Keyed by `"person"`, `"system"`, `"container"`, `"component"` |
| `relationship_style` | `RelationshipStyle` | Required | Applied to all diagram relationships |

**Validation rules**:
- `styles` MUST contain entries for all four element kinds; missing entries are a schema validation error
- `locked` typed as `Literal[True]` — Pydantic rejects any value other than `True`; enforces FR-001/FR-004 at the Python type level
- `version` validated against `^[0-9]+\.[0-9]+\.[0-9]+$` pattern

### `RenderRequest`

Input to the render API. Note: no style fields — FR-002 is enforced at the type level by the absence of any style-related fields.

| Field | Type | Constraints | Notes |
|---|---|---|---|
| `level` | `C4Level` | `"context" \| "container" \| "component"` | Which C4 projection to render |

### `RenderResult`

Output from the render pipeline.

| Field | Type | Notes |
|---|---|---|
| `design_id` | `str` | Design that was rendered |
| `level` | `C4Level` | C4 level that was rendered |
| `dsl` | `str` | Structurizr DSL source (UTF-8 text) |
| `svg` | `str` | SVG XML as a string |
| `png_base64` | `str` | PNG image bytes, base64-encoded |

### `ThemeValidationError`

Raised (and converted to HTTP 422) when theme validation fails.

| Field | Type | Notes |
|---|---|---|
| `message` | `str` | Human-readable description of the failure |
| `failing_constraint` | `str` | Name of the JSON Schema keyword or field that failed |

- `container`: white `#ffffff` on `#438DD5` → ~4.6:1 ✅ (just above AA threshold)
- `component`: black `#000000` on `#85BBE0` → ~5.9:1 ✅

## SVG Layout Model

The SVG generator uses a **fixed grid auto-layout**:

```
Canvas width:  max(elements * 220, 800)
Canvas height: ceil(elements / 4) * 150 + 60
Cell width:    200px
Cell height:   120px
Column count:  4 (configurable constant)
Margin:        20px (left/top)
```

Element positions are deterministic (stable sort by `element.id`), ensuring SC-006 (byte-identical output). Position hints from the ADP-SPEC-009 layout API are optional; when provided, they override the auto-layout for each element.
